Solicitud manual

Puedes registrar un envío individual o crear un lote de varios envíos manteniendo cada número como expediente independiente.

Registro múltiple / lote

Una línea por envío: Nº ENVÍO ; CLIENTE ; UBICACIÓN ; OBSERVACIONES. Cada número se guardará como un expediente independiente.

Formato de importación: ENVÍO ; CLIENTE ; UBICACIÓN ; OBSERVACIONES ; PRIORIDAD. Las dos últimas columnas son opcionales. Se comprueban duplicados antes de guardar.

Modo escáner

Escanea o escribe un número de envío y pulsa Enter. El lector de códigos funciona como teclado.
